Claude API Key

Get your key at console.anthropic.com → Settings → API Keys

How to get a Claude API key:
1. Go to console.anthropic.com and sign in
2. Click Settings → API Keys → Create Key
3. Copy the key (starts with sk-ant-api03-…) — only shown once
4. Paste it above — saved automatically in your browser
The key is stored only in localStorage on this machine. It is never sent anywhere except directly to the Anthropic API.
