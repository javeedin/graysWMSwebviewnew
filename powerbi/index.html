Dataset definitions

What goes into Power BI

A dataset here is a set of tables, each an APEX SQL query, plus measures (DAX) and relationships. Power BI Desktop gives you the code to load it into Power BI Desktop straight from APEX (no app registration); with an app registration, Publish and Refresh push it from the app.
