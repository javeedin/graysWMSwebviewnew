Deploy the query runner

Creates the folder, the DBMS_XMLGEN data model and the report through CatalogService, then runs SELECT 1 FROM dual. Needs BI Author once.

Manual setup (if auto-deploy is not allowed)
  1. BI Publisher → New → Data Model. Data source ApplicationDB_FSCM.
  2. Properties: Include Parameter Tags ✓, Include Empty Tags for Null ✗, Include Group List Tag ✗, XML Tag Display = Upper case.
  3. New data set Q1 → SQL Query → Standard SQL, paste the SQL below. Accept the bind P_QRY_STMT (String).
  4. Save as .
  5. Create Report → use the data model → no layout (data only, XML + CSV allowed). Save as .
