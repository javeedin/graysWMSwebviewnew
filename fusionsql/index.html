  1. BI Publisher → New → Data Model. Data source ApplicationDB_FSCM.
  2. Properties: Include Parameter Tags ✓, Include Empty Tags for Null ✗, Include Group List Tag ✗, XML Tag Display = Upper case.
  3. New data set Q1 → SQL Query → Standard SQL, paste the SQL below. Accept the bind P_QRY_STMT (String).
