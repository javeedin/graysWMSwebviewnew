One fast, shared dataset — DuckDB module files loaded from APEX and Oracle Fusion, read by every PC

Modules

Your data, one model

A module is one DuckDB file (e.g. wms, gl, ap). Each table in it is loaded from APEX or Oracle Fusion by SQL — in full, or only the rows changed since the last refresh. The refresher PC publishes a new version; every PC reads it.
