Everything this assistant can do
Ask in plain English on the Chatbot tab — type / for shortcuts. ✋ approval = nothing executes until you approve a card. ⚡ instant = read-only, runs immediately. Everything follows the PROD / TEST chip in the top bar.
Ask anything about your data ⚡ instant
I write and run read-only Oracle SQL on the WMS schema — trips, orders, shipment lines, print jobs, agents, jobs, logs. Results export to Excel / CSV / PDF.
"Give me the list of trips for today" · "How many print jobs failed this week by day?"
Interactive selection grids ⚡ instant
Ask for a list "in a selectable grid": tick the rows you want and click an action button (e.g. cancel the selected lines).
"/trip-manual-lines" · "Show order 418978's lines in a selectable grid so I can cancel some"
Cancel lines — WITH child lines ✋ approval
The Shipping-Agent rule, on demand: cancelling main line 3 also cancels 3.1, 3.2…; if there are no numbered sub-lines I read the BOGO promo mapping and cancel the promo child items of the same order. Children already cancelled / shipped / interfaced are skipped and reported. You see the full plan (main ↳ children, via SUB-LINE or BOGO) before one approval per order.
"Cancel the Manual Reservation lines of order 418978 including child lines"
Trip operations ✋ approval
Create a trip (prefilled form), add pasted orders to it (validated against pending shipments, valid ones pre-ticked), update the trip header, remove an order from a trip. I remember the trip we just created for follow-ups.
"/create-trip" · "Add these orders to that trip: 418978, 419001, …"
Pickers & picking ✋ approval
Assign a picker to an order, trip-level picker assignment, call a pick wave, run pick release for an order, update pick confirm status, release picks.
"Assign picker 14 (John) to order 418978" · "Run pick release for order 419001"
Oracle Fusion direct ✋ approval for writes
Say "fusion" and I use the live Fusion REST APIs: shipment lines, sales orders, staged inventory transactions, pick/ship transactions. Reads are instant; every write shows an approval card with the exact request.
"fusion: show the shipment lines of order 418978" · "/fusion-…" commands
Saved reports ⚡ instant
Save any answer as a re-runnable report with typed parameters (trip, date range…). Run it from the Saved Reports tab or from chat — always live data, always exportable.
"Save this as a report" · "/reports"
Scheduled background jobs ✋ approval
"Every 10 minutes until done" jobs that run INSIDE Oracle — SQL checks + REST steps chained with extracted values — even when this app is closed. Monitor, run-now or cancel them in the Scheduled Jobs tab.
"/schedule" · "every 10 min cancel trip 6812's manual lines until none are left"
Print — results & order documents ✋ approval
Print any result grid as a paginated table, or print real Sales Order PDFs (downloaded from Oracle BI Publisher) — one order or a whole trip (max 20). Uses your default printer (🖨 button) or one you name; the printer list also browses shared network printers you can connect.
"/print-order 418978" · "/print-trip-orders 6812" · "/printers"
Download order PDFs ⚡ instant
Sales Order PDFs saved straight into your download folder (📁 button), named {order}.pdf, no questions — then I show you the folder's file list.
"/download-trip-orders 6812" · "/my-files"
Email results ✋ approval
I compose the mail with your data as a table; you review recipients and body in a card; it sends from your Office 365 account (✉ button to configure once).
"Email this to dispatch@grays.com with a short summary"
Database changes ✋ approval
Create tables, insert / update / delete rows — I compose the exact statement, you approve it in a card. New tables join my schema catalog automatically. Every API run is also audit-logged to WMS_AI_API_LOG.
"Create a table for driver check-ins" · "Record trip 7833 as downloaded"
This PC ⚡ instant
List installed printers (default marked), browse network printers, show machine / user / OS / drive space, list your downloaded files.
"/printers" · "/sysinfo" · "/my-files"
Settings that steer me
PROD/TEST chip — every query, Fusion call, form and job follows it. ⚙ Engine — Claude CLI (subscription) or API key. 🖨 Default printer · 📁 Download folder · ✉ Email account. All per PC.
"/engine" · "/default-printer" · "/download-folder" · "/email-settings"
Safety: I can only run whitelisted operations — reads are SQL-only (SELECT), writes are the catalogued webservices behind approval cards, scheduled jobs are capped (≤200 runs, ≤30 days, whitelisted hosts), and every write-API run is audit-logged with your name and machine. Authority policies (WMS_AI_POLICIES) let an admin set, per user / action / instance: AUTO (I act without asking — I always say so), ASK (approval card, the default) or DENY (I refuse and say who to ask).
