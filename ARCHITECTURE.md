## Summary

This Warehouse Management System (WMS) is a **hybrid desktop-web application** that combines:

1. **Windows Forms (.NET 8.0)** - Desktop shell for native Windows integration
2. **WebView2 (Chromium)** - Modern web rendering engine
3. **JavaScript SPA** - Single-page application for the UI
4. **DevExtreme** - Enterprise-grade UI components
5. **Oracle APEX** - Cloud database and REST APIs
6. **Oracle Fusion** - ERP integration for orders and reporting
7. **Claude AI** - Intelligent assistant capabilities

The architecture enables seamless integration between web technologies and Windows-native features like printing, file system access, and hardware integration.
